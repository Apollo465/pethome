## 一、四个硬门槛

### 1. 应用签名（技术问题，半小时可完成）

现状：`build-profile.json5` 里 `signingConfigs` 为空，构建产物是 `entry-default-unsigned.hap`。

操作：
1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) → 我的应用 → 新建应用，包名填 `com.pethome.xiaohong`；
2. 「证书、App ID 和 Profile」→ 生成发布证书（.cer）与发布 Profile（.p7b）；
3. DevEco Studio → File → Project Structure → Signing Configs，取消勾选自动签名，填入发布证书、Profile、密钥库；
4. 构建 release 包：`hvigorw assembleHap --mode module -p product=default -p buildMode=release`；
5. 用 `hap-sign-tool` 或 DevEco 直接产出已签名 HAP（产物名不含 `unsigned`）。

自检：解包 HAP，`module.json` 应为 `"debug": false`、`"buildMode": "release"`。

### 2. 隐私政策（两处，缺一不可）

审核指南 7.1：**AGC 上要填隐私政策网址，应用内也要能便捷查看，两处内容必须一致**，且需包含开发者名称、处理目的/方式/范围、用户权利与投诉渠道。

材料：`privacy-policy.md`（本目录）——把 `【】` 占位替换成真实信息后：
1. 挂到一个可公开访问的网址（可用 Gitee Pages / 个人博客 / 静态托管），把网址填到 AGC；
2. 应用内「我的 → 关于 → 隐私政策」展示同一份内容（应用内页面已实现）。

### 3. 首次启动隐私弹窗

审核指南 7.5：必须用弹窗等形式明示并取得同意后才处理个人信息。

**当前做法（2026-09-15 调整）**：应用已接入华为平台隐私声明托管服务，首次启动由系统统一弹出标准隐私声明，
应用内**不再自建同意弹窗**（第一次提审被驳回意见 4：两个弹窗影响体验）。
应用内保留隐私政策页，可阅读全文、删除本机数据、撤回同意（撤回后调用 `privacyManager.disableService()`，
下次启动系统重新弹窗）。
